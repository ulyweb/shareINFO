ADD CUBEMAP

Six square face images — same size each. Front, back, left, right, up, down.

ADD MULTIRESOLUTION

Point to a pre-tiled cube pyramid (output of the Marzipano or Pannellum tiler) hosted alongside the tour.
Tiles are referenced by URL, not embedded — deploy the tiles folder next to the exported tour.

ADD 360° VIDEO

Equirectangular (monoscopic) video. Reference a self-hosted file deployed next to the tour, or pick a local file to preview now.
Video is referenced by URL, not embedded — deploy the file next to the exported tour. Hotspots, masks and image adjustments don't apply to video scenes.

ADD FROM URL

Load an equirectangular panorama from any hosted image — an Imgur direct link (i.imgur.com/xxxx.jpg), your own server, etc. The image is referenced by URL, not embedded.
Must be a direct image link and allow cross-origin use (Imgur's i.imgur.com works). If the image is CORS-blocked it won't render as a texture.
